# 종목 상세의 주간 30분봉 (2026-09-16)

## 사용자 확정 범위

- 대문에서 티커를 눌렀을 때 나오는 패널은 유지한다. `SOXX 페이지 열기` 같은 링크로 이동한 `/symbol/[symbol]`에서만 주간 차트를 표시한다.
- PC에서는 기존 종목 요약 오른쪽, 모바일에서는 요약 아래에 표시한다. 대문 벤치마크·패널의 기존 `PriceChart`는 수정하지 않는다.
- 미국 정규장 월~금 다섯 칸을 고정하고, 30분 OHLC 봉이 도착한 자리만 채운다. 일반적인 정규장은 하루 13개, 일주일 최대 65개다. 휴장·조기 폐장·미수신 구간을 가짜 봉으로 채우지 않는다.
- 최신 사용자 요청(2026-09-16): 캔들 등락 가독성을 우선한다. 가격 축은 실제 주간 고가/저가(꼬리 포함)에 각 12% 여백을 둔다. ±1σ·±2σ 중 화면 안의 선이 하나도 없으면 가장 가까운 선 하나까지 확장한다(동률은 −1σ 우선). 이미 하나라도 보이면 추가 확장하지 않는다. 모든 σ 포함 규칙으로 되돌리지 말 것. 봉이 없을 때만 ±1σ 범위를 임시 기준으로 쓴다.

## 구현·운영

- `lib/weekly-chart.ts`: ET 주간 선택·OHLC 검증·슬롯·축 범위의 단일 출처. 기존 `calendar-state.ts`의 시간대 함수를 재사용한다.
- `lib/weekly-chart-server.ts` → `/api/weekly-chart/[symbol]` → `components/dashboard/weekly-price-chart.tsx`. API는 시장 전체 스냅샷을 읽지 않는다.
- 별도 Yahoo Finance chart 피드의 `range=5d&interval=30m&includePrePost=false`를 사용한다. 기존 레버리지 계산기도 Yahoo 가격을 쓰지만 주간 차트는 독립 경로다. UW 스냅샷·σ 계산·발행 잡·알람은 변경하지 않는다.
- 반환된 최근 5거래일 전체를 그대로 그리지 않는다. 현재 ET 달력의 월~금만 남긴다. 주말에는 끝난 주를 유지하고 월요일 ET에 새 주로 전환한다. 금요일 마감 후 σ 밴드가 다음 주로 넘어가도 차트는 끝난 주의 실제 거래를 유지한다. 해당 주의 현재/과거 밴드만 선택하며, 다른 주 밴드를 겹쳐 그리지 않는다.
- 정규장 `tradingPeriods`와 09:30~16:00 필터를 함께 적용한다. Yahoo의 16:00 종가 단일값 행은 30분봉이 아니므로 제외한다. 조기 폐장의 마감시각 행도 제외한다.
- 당일 진행 중인 봉은 흐리게 표시하고 `진행 중`으로 구분한다. 마감 여부는 해당 30분 구간 종료시각으로 판단한다.
- 상세 페이지 최초 진입에 1회 조회한다. 자동 조회는 평일 09:32~16:02 ET의 30분 경계에서 보이는 탭에만 실행한다. 16:02는 마지막 봉 확인이다. 장외·주말에는 주간 전환 확인용 로컬 타이머만 돌고 네트워크는 호출하지 않는다. 같은 30분 구간 내 탭 복귀는 재조회하지 않는다. 수동 확인도 브라우저/CDN 캐시를 우회하지 않는다. 대문이나 링크 프리페치에서는 피드를 조회하지 않는다. 별도 휴장 캘린더는 추가하지 않아 평일 휴장·조기 폐장일은 이 시간 창 안에서 최대 30분마다 확인할 수 있다.
- 브라우저·Vercel CDN·서버 메모 캐시가 같은 :02/:32 경계에서 만료된다(최대 30분). 메모는 티커+ET 주간별 최대 128개이며 동시 요청을 합친다. 이미 20분 지난 응답을 다시 30분 캐시하지 않는다. URL의 `week`로 주간 캐시를 분리하고 주 불일치는 409다. 오류는 HTTP `no-store`, 서버 실패 캐시는 10초, 피드 제한시간은 8초다. `Cache-Control`과 `Vercel-CDN-Cache-Control`을 함께 설정한다.
- 조회 실패를 정상 빈 데이터로 바꾸지 않는다. 최초 실패는 오류를 표시하고, 갱신 실패는 같은 주 마지막 자료와 실패 문구를 함께 표시한다. 주가 바뀌면 이전 주 자료를 재사용하지 않는다.
- 차트에 Yahoo Finance·지연 가능·확인시각(ET)을 표시한다. 좌측 최종 마감은 UW 스냅샷, 우측 봉은 Yahoo OHLC이므로 서로 다른 피드이며 마감 단일값과 최종 봉 종가가 다를 수 있다. 한쪽으로 다른 쪽을 덮어쓰지 않는다. 피드 지연시간의 상한은 미검증이다.

CRDO처럼 앵커에서 멀리 떨어진 주는 봉 전체가 화면의 10% 안쪽으로 눌렸다.

### 축 (`lib/weekly-chart.ts`)

- `candleDomain(candles, band, extraPrices, fit)`의 네 번째 인자 `AxisFit`이 축 개념을
  하나로 모은다. `candles`(기본) / `sigma` / `all`(UI 표기 `전체`). 이전의 `GEX까지 맞춤`
  체크박스 + 암묵적 σ 규칙이라는 두 축 개념을 없앴다.
- `candles`에서만 4번 절의 "캔들 우선 + 가장 가까운 σ 하나" 규칙이 돈다. `sigma`/`all`은
  사용자가 명시적으로 고른 넓은 축이다. **기본값을 `candles`가 아닌 것으로 바꾸지 말 것.**
- `priceTicks(floor, ceiling, target)`이 1/2/2.5/5/10 단위의 반올림 눈금을 만든다.
  임의 간격 눈금으로 되돌리지 말 것.
- CRDO 실측: 26봉 $149.15~$154.74 → 축 $148.48~$155.41. 봉이 플롯 높이의 81%를 채운다.

### 레이아웃 (`components/dashboard/weekly-price-chart.tsx`)

- 플롯 높이 360 → 폭에 따라 320/400/452. 가격 축 여백은 약 114 → 67px.
  레벨 **이름**은 플롯 안쪽에 인라인으로 그리고 축 여백에는 **가격만** 남겨서 좁혔다.
- 좌상단 OHLC 리드아웃(TradingView/Webull 방식). 등락률은 **직전 봉 종가** 대비이며
  직전 봉이 없을 때만 자기 시가를 쓴다. 미완성 봉은 `진행 중`을 덧붙인다.
- 포인터: 수평선 + 우측 가격 태그, 세로선은 hover 중인 봉에 스냅. 시각은 x축 **아래**
  알약 라벨(`chartTimeLabel(...).slice(5)` = 연도 제거).
- 화면 밖 ±1σ·GEX는 `↑ 축 밖 · +1σ $176.44` 칩으로 알리고, **누르면 축이 넓어진다**
  (σ만이면 `sigma`, GEX가 섞이면 `all`). ±2σ는 화면 밖이 정상이라 칩을 만들지 않는다.
- SVG 위에 `pointer-events-none` HTML 오버레이를 겹쳤다. SVG가 CSS 픽셀과 1:1이라
  좌표 변환이 필요 없다.
- 툴바 한 줄로 축소: 좌측 OI 기준일, 우측 `GEX` / `S2·R2` / `캔들 | ±1σ | 전체`.
  세 번째 버튼은 사용자 지시로 `GEX 포함` → **`전체`(en: `Full`)**로 바꿨다. 옆의 `GEX`
  칩은 선을 켜고 끄는 토글이라 "GEX"가 들어간 이름이 기능과 헷갈렸다. 세 버튼은 전부
  **축 범위**만 뜻해야 하므로 여기에 GEX/σ 같은 데이터 이름을 다시 넣지 말 것.
  대신 버튼별 `title`로 각 범위가 뭘 포함하는지 설명한다.
  길던 S2·R2 설명문은 `title` 속성으로, 3줄 GEX 범례는 1줄로 옮겼다.

### 색 (`app/globals.css`)

- 하드코딩 `#4da3ff`/`#ff6478`(라이트 모드 무시)를 테마 토큰 `--gex-support`(파랑 250)·
  `--gex-resistance`(빨강 16)로 바꿨다. 채도를 σ 램프보다 높게 둬서 GEX 파랑이
  −1σ 파랑과 구분된다. 하드코딩 hex로 되돌리지 말 것.

### 축 여백 태그 충돌

`separatePriceLabels`에 **최종가 태그도 함께 넣어** 22px 간격으로 벌린다. 예전처럼
최종가만 `y(last.close)` 원위치에 그리면 σ/GEX 태그와 겹친다(±1σ 축에서 재현됨).
눈금 라벨 숨김 판정도 레벨이 아니라 이 합친 결과(`placed`)를 기준으로 한다.
