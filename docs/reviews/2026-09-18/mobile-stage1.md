## 확인된 변경

- 모바일 홈 상단에 검색, 가격 기준 시각, My Sigma 요약, 관심 종목 카드가 표시된다.
- 하단 내비게이션에 홈·탐색·My Sigma·더보기를 배치했다. 더보기는 기존 계산기·가이드·캘린더·리포트 경로로 연결된다.
- 모바일 종목 카드와 표의 종목 본문은 `/symbol/[symbol]`의 실제 링크가 된다. 별표 관심 버튼은 링크의 형제 요소다.
- 기존 `sigma-personal-watchlist` 키와 10개 제한, 대문자 정규화, 중복 제거, 데이터에 없는 저장 심볼 보존을 유지했다.
- 목록 필터·검색·정렬을 세션에 보존하고, 홈을 떠났다가 뒤로 돌아오면 저장한 스크롤 위치를 복원한다. 검색 Enter와 표의 빈 영역 이동도 같은 위치 저장 경로를 사용한다.
- Web Share API 성공·취소·실패를 구분한다. 취소는 오류로 알리지 않고, 미지원/실패는 클립보드 복사 후 수동 복사 입력으로 내려간다.
- 종목 상세에 가격 기준 시각과 밴드 기간을 분리해 표시하고, 기존 주간 30분봉·캔들/±1σ/전체·GEX 차트 컴포넌트는 재사용했다.
- 관심 목록은 외부 저장소 이벤트를 하나의 리스너로 처리하며, 다른 라우트에 머문 뒤 다시 구독할 때 브라우저 저장값을 재확인한다.
