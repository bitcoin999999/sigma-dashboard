# My Sigma·포트폴리오·가격/σ 이력 (2026-09-22)

## 계산 정의

- σ 산출의 유일한 출처는 oi_shock/sigma_core.py. 웹은 이미 발행된 anchor/sigmaPercent로 기존 lib/sigma.ts의 위치 계산과 상태 판정을 재사용한다.
- 관심목록 요약은 동일가중 mean(z), mean(abs(z)), 기존 상태 판정에 따른 ±1σ 경계 밖 개수, 유효/전체 개수다. 정확한 ±1도 경계 밖에 포함한다. 표시용 반올림을 판정에 사용하지 않는다.
- 경계 근접은 기존 보드의 0.85 ≤ |z| < 1을 상수로 통합했다. 새로운 신호 임계값이 아니다.
- snapshotId, 밴드 창, 종가 세션, methodVersion, priceBasis가 같아야 한다. 앵커 IV임을 확인할 수 없으면 평균을 숨긴다. 주중 IV를 과거 앵커 IV처럼 취급하면 선행 정보가 섞인다.
- 2026-09-21 자료 123종목 중 97개가 fromAnchor=true, 26개가 false였다. 가격/σ 원본은 바꾸지 않고 기준 메타데이터만 덧붙였다.
- 없는 종목/σ는 null. 분모는 유효 개수, 전체 저장 개수는 유지한다. +2와 −2의 평균은 0, 평균 절대 위치는 2다.

## 포트폴리오

`lib/portfolio.ts`가 계산 단일 출처다. 두 기능은 구별한다.

1. 비중 시뮬레이션: 기간 시작 비중으로 매수 후 보유, 리밸런싱 없음, 현금 이자 0. V(t)=cashWeight/100 + Σ weight_i/100 × price_i(t)/price_i(start). 기간 수익=(V(end)−1)×100. 일간 수익=(V(end)/V(prev)−1)×100. 기여도는 %p이며 합이 기간 수익과 같다. 기말 비중은 가격에 따라 달라진다.
2. 보유 관리: 수량·평단·보유 기준일. 현재 평가금액 입력 시 현재 종가로 수량을 한 번 환산해 고정한다. 평가손익=수량×(현재가−평단). 일간 손익은 이전 세션부터 동일 수량을 보유했을 때만 제공하며 전일 평가액이 분모다.

실제 계좌의 현금흐름/TWR/IRR, 매매 원장, 배당·FX·수수료·기업행동 자동 처리는 구현 범위에 없다. 화면에도 명시한다. 보유정보 변경은 사용자가 직접 입력한다.

공통 가격이 없는 종목은 재가중하지 않는다. 요청 기간 자료가 부족하면 기간을 몰래 줄이지 않는다. SPY 거래일이 확보돼 있으면 공동 누락일도 검사한다. 현재는 원본의 20거래일만 초기 이력으로 확보했다. 다음 발행부터 이미 조회하는 OHLC(최대 1000봉)를 별도 이력에 누적한다.

## 브라우저 저장

- 기존 관심목록 키/한도 20은 그대로 유지.
- `sigma-personal-portfolios:v1`: allocations, cashWeight, holdings, revision. 이전 정상 문서는 `:backup`에 백업하고 저장한다. JSON 내보내기/검사 후 명시적 가져오기 제공. 손상 자료를 자동 삭제하지 않는다.
- `sigma-watchlist-observations:v1`: 최대 4관측, snapshot/date/band/basis와 symbol별 z만 보관. 차트/GEX/계좌정보는 넣지 않는다.
- 같은 ID는 비교하지 않으며 같은 세션 정정도 새 경계 통과로 세지 않는다. 새 주간 창은 별도 이벤트. 새로 추가한 종목은 데이터 복구로 세지 않는다.
- 다른 탭 저장이 감지되면 입력 초안을 유지하고 덮어쓰기를 거부한다. 초안 내보내기/저장본 불러오기로 해결한다.
- 보유정보·평단·금액·전체 티커 배열을 분석 이벤트에 넣지 않는다. 서버에 포트폴리오를 저장하지 않는다.

## 가격/σ 차트

- Recharts SVG. 위: 종가와 해당 주 ±1σ 음영, 아래: 같은 날짜 축의 σ. 주마다 선을 끊어 밴드 재설정을 가격 복귀처럼 그리지 않는다.
- 금요일 종가는 끝난 주의 밴드에 속한다. 새 앵커의 0σ로 덮어쓰지 않는다.
- fromAnchor=true인 과거 밴드만 σ/이탈 후 표본에 사용한다. 기준을 확인하지 못한 구간은 가격만 표시한다.
- 완료 주의 ≥+1σ / ≤−1σ 필터, 1·2·4주 후 가격수익, 선택 마감가를 0%로 놓은 후속 가격 경로. 단순 관찰이며 예측력은 **미검증**. 아직 도래하지 않은 기간은 —.
- 공개 이력은 `/snapshot/history/SYMBOL.json`. 서버가 현재 스냅샷과 병합하며 오류 시 현재 확보된 이력만 표시한다. 없는 과거 밴드를 현재 IV로 복원하지 않는다.

## 공유·SEO

- 공유 카드 1080×1350, OG 1200×630. 공통 symbolCardData → Next ImageResponse. 화면 캡처/차트 캡처가 아니다. 폰트는 라이선스와 함께 저장했다.
- 이미지 준비와 공유를 별도 사용자 클릭으로 분리. files canShare 확인, 미지원/실패는 다운로드, AbortError는 취소로 처리.
- 이미지 URL은 실제 snapshotId를 포함한다. 원본 정정 후에도 같은 숫자를 쓰도록 공개 축약 revision을 90일 제공한다. 만료된 이미지는 410이며 최신 수치로 몰래 대체하지 않는다. 종목 페이지 링크 자체는 최신 페이지다.
- invalid ticker는 스트리밍 시작 전 proxy.ts에서 실제 HTTP 404. valid symbol 메타데이터/HTML의 언어와 숫자가 같은 loadBoard를 사용한다. canonical/sitemap 및 기존 force-dynamic 정책은 보존.
- 관련 종목은 현재 자료의 같은 분류 섹터, 겹치는 테마 수, 티커순으로 최대 6개. 무작위 선정 없음.

## 운영

실제 데이터 소스는 Blob이 아니라 `https://sigma-snapshot-data.vercel.app/snapshot/latest.json`이다. oi_shock의 기존 발행 잡이 이력도 함께 배포한다. 주간 σ 캐시 KEEP_WEEKS, launchd 시간, 알람 채널, dedup/schedule 상태는 수정하지 않는다.
