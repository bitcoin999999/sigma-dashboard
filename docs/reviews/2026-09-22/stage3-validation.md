## 실제 브라우저에서 확인

로컬의 공개 종가 자료와 테스트용 입력만 사용했다. 실제 사용자 보유정보를 읽거나 입력하지 않았다.

- NVDA·TSLA 저장 → My Sigma 평균 +0.59σ, 분석 2/2, 경계 밖 0/2.
- 두 종목 비중 60/40, 현금 0. 2026-09-14→09-21 모형 +6.49%, 일간 +2.58%, $10,000→$10,648.97. 기여도 4.67%p/1.82%p, 기말 비중 60.73%/39.27%.
- 테스트 NVDA 10주, 평단 $200: 평가 $2,273.80, 미실현 $273.80(+13.69%), 전일 이전부터 보유한 경우 일간 $51.10(+2.30%). 등록일이 현재 세션이면 일간 손익은 미제공.
- 저장 후 새로고침 복원. 보유 저장 후 탭 유지.
- 360/390/430/1440px에서 document.scrollWidth = clientWidth, 가로 넘침 없음(포트폴리오 보유 화면). 390px 모델·상세 페이지 DOM 확인.
- UI 도구의 date fill은 DOM 값만 바꾸고 React 이벤트를 보내지 않는 경우가 있어 실제 키보드 입력으로 보유 기준일을 검증했다.
- CUA 캡처가 축소된 합성 화면으로 반환되는 제약이 있었다. 레이아웃 수치는 DOM으로 별도 검사했다.

## 아직 실행하지 않은 실기기 수동 점검

- iOS Safari, Android Chrome, Kakao 인앱: 이미지 준비 후 파일 공유/저장, 취소, 복귀, 다운로드 위치 확인.
- 각 실기기: 숫자 키패드·날짜 선택, 20개 목록, 키보드가 열린 상태에서 저장 버튼 접근.
- 실제 OS 공유 시트로 다른 사람에게 이미지를 전송하지 않았다. 파일 API 지원/미지원/AbortError는 자동 테스트로 검증했다.
- 장기 운영: 다음 정규 발행 후 신규 가격/밴드 누적 및 이후 1·2·4주 결과 확인. 아직 발생하지 않은 주간 결과를 검증 완료라고 하지 않는다.
