# 헤더 검색과 상세 차트 GEX (2026-09-16)

- 헤더 언어 선택 왼쪽의 검색은 기존 스냅샷에 등록된 티커만 접두어로 검색한다. 대소문자를 구분하지 않고 알파벳순으로 표시한다. 검색용 API 호출과 링크 prefetch는 없다. 방향키/Enter/Escape 지원.
- 상세 페이지의 주간 30분봉에 ±1σ/±2σ와 GEX를 표시한다. 홈페이지 벤치마크와 팝업은 변경하지 않는다. 상태 임계값 ±1.5σ는 그대로다. σ 가격 변환은 lib/sigma.ts의 sigmaPriceRange를 공유한다.
- upstream support/resistance의 양수 netGex 순위를 그대로 사용한다. 현재 가격으로 역할을 다시 분류하거나 Greeks/OI를 재계산하지 않는다. 기본 S1/R1, 선택 S2/R2 및 전체 표시 토글.
- 잘못된 숫자/비양수는 제외하고 같은 행사가 중복은 최댓값으로 정리한다. 양쪽 역할에 같은 행사가가 있으면 제외한다. profile에서 행사가/금액이 일치하지 않으면 점유율은 null, 강도 강조는 하지 않는다. 후보 하나의 dominance는 Infinity 대신 null이다.
- 강한 후보는 주 후보의 양수 profile 내 비중 15% 이상, 다음 후보 대비 2배 이상(단독 후보 제외 조건 없음)이다. 기존 gex-floor.ts 상수를 공유한다. 이 강도 기준은 미검증이나, 2026-09-16 사용자의 명시적 요청으로 UI의 미검증 문구는 제거했다. 검증이 완료되었다는 뜻은 아니다. profile은 발행된 부분집합이므로 전체 옵션 체인 비중이라고 해석하면 안 된다.
- 보라색 -1σ 합치는 기존 findGexFloor 결과를 유지하며 가격/밴드 주차까지 일치할 때만 표시한다. 상단 합치 신호는 추가하지 않는다.
- 선은 최신 스냅샷 참고선이고 OI 기준일을 명시한다. 과거 시점별 GEX 재구성이 아니다. chart week가 다른 패킷은 숨긴다. 값은 고정하고 충돌 시 라벨만 이동한다.
- 기본 가격 축은 실제 봉의 주간 고가/저가와 여백으로 정한다. 먼 σ 선은 표시하지 않는다(최신 사용자 요청). 먼 GEX는 축 밖 가격 목록에 남기고 'GEX까지 맞춤' 선택 시만 축을 확장한다.
- 기존 장중 30분 간격 갱신과 공유 캐시를 유지한다. GEX/검색은 별도 데이터 수집을 추가하지 않는다.

검증: 전체 53개 테스트, 변경 파일 ESLint, webpack 프로덕션 빌드 통과. 현재 108개 종목의 모든 파생 σ 값/상태/findGexFloor 결과가 수정 전과 동일함을 비교했다. 로컬 브라우저에서 검색, 상세 페이지 이동, GEX 끄기/보조선/축 맞춤을 확인했다. SOXX 26봉 및 월~금 고정 축, 네 σ 라벨, OI 2026-09-15 표시 확인.
